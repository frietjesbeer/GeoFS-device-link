Functions:
- Adds a PFD on your smartphone or tablet
- Autopilot panel and some other handy things so you can control your flight from anywhere

Check out the website and test the addon yourself if you're curious:
https://frietjesbeer.github.io/GeoFS-device-link/


Just add the userscript to tampermonkey, load GeoFS and connect it to the website via the peer code and the token the addon will give you.
